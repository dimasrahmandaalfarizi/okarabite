# Okara Bite - Turning Food Waste into Healthy Delight

Okara Bite is an innovative upcycled snack brand that transforms nutrient-rich soy pulp (okara) into delicious, high-fiber, gluten-free artisan biscuits.

## ✨ Features

- **Waste-to-Taste Storytelling:** Educational, data-driven narrative showcasing okara upcycling, fiber metrics, and zero-waste impact.
- **Interactive 3D Biscuit Experience:** Real-time 3D interactive biscuit visualizer built with Three.js and React Three Fiber with dynamic flavor switching (Original, Rich Chocolate, Ceremonial Matcha).
- **Sensory & Nutrition Breakdown:** Deep dive into clean ingredients, low GI benefits, and nutritional comparisons.
- **Modern Artisan UI:** Built with sleek typography, smooth animations, and zero-clutter modern design principles.

## 🛠️ Tech Stack

- **Framework:** React 19 + TypeScript + Vite
- **3D Graphics:** Three.js + React Three Fiber + Drei
- **Animations:** Framer Motion
- **Styling:** Tailwind CSS v4 + Vanilla CSS Design Tokens
- **Icons:** Lucide React
- **Deployment:** Vercel

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/dimasrahmandaalfarizi/okarabite.git

# Navigate to project directory
cd okarabite

# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```
